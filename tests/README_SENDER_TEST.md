# 发送端测试指南

## 背景

在EEG数据处理系统中，数据集仅挂载在发送端容器（data-sender）中，而不在处理器端容器中。因此，测试发送和接收功能时，应该在发送端容器中运行测试脚本，而不是在处理器端容器中。

## 新测试脚本

我们创建了一个专门在发送端容器中运行的测试脚本 `test_sender_in_container.py`，它具有以下特点：

1. 在同一容器中同时模拟发送端和接收端
2. 使用本地回环地址（127.0.0.1）进行通信测试
3. 直接访问发送端容器中挂载的数据集
4. 提供详细的测试过程输出和结果验证

## 使用方法

### 在发送端容器中运行测试

1. 首先，进入发送端容器：

```bash
docker exec -it data-sender bash
```

2. 在容器内运行测试脚本：

```bash
python -m tests.test_sender_in_container
```

### 命令行参数

测试脚本支持以下命令行参数：

- `--subject` 或 `-s`：指定受试者ID（默认为"01"）
- `--task` 或 `-t`：指定任务名称（默认为"rest"）
- `--dataset` 或 `-d`：指定数据集根目录路径（默认为容器中的"/app/data/ds005779"）

示例：

```bash
python -m tests.test_sender_in_container --subject 02 --task motor
```

## 测试流程

测试脚本会执行以下步骤：

1. 在本地启动一个模拟的接收器服务（监听127.0.0.1:9000和9001端口）
2. 创建一个EEGDataSender实例，配置为连接到本地模拟接收器
3. 发送元数据并验证接收器是否成功接收
4. 开始流式发送EEG数据并验证接收器是否成功接收数据包
5. 输出详细的测试结果

## 故障排除

如果测试失败，请检查以下几点：

1. 确保数据集已正确挂载到发送端容器中
2. 检查指定的受试者ID和任务名称在数据集中是否存在
3. 查看测试输出中的错误信息，了解具体失败原因

## 注意事项

- 此测试脚本仅测试发送和接收功能，不测试与Spark处理相关的功能
- 测试脚本使用加速发送模式（speed_factor=10.0）以缩短测试时间
- 如果需要测试完整的数据处理流程，请使用docker-compose启动完整的系统环境
