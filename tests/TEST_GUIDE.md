# EEG数据处理系统测试指南

本指南将帮助您在Docker环境中正确测试EEG数据发送器和接收器的连接。测试需要在不同容器间进行通信，确保发送端和接收端能够正确连接。

## 测试环境准备

### 1. 确认Docker容器状态

在开始测试前，请确保所有必要的Docker容器已经启动并正常运行：

```bash
# 查看当前运行的容器
docker ps
```

您应该能看到以下容器正在运行：
- spark-master
- spark-worker
- 其他相关服务容器

### 2. 启动Java网关服务

**重要提示**：测试前必须手动启动Java网关服务，因为Docker容器没有配置自动启动此服务。

```bash
# 进入java-gateway容器
docker exec -it java-gateway bash

# 进入src目录
cd /app/src

# 启动Java网关服务
python common/start_dedicated_gateway.py
```

请在新的终端窗口中保持Java网关服务运行，然后在另一个终端窗口中继续以下测试步骤。

### 3. 准备测试环境容器

测试涉及两个不同的容器：一个用于发送端，一个用于接收端。

#### 3.1 进入发送端容器（Spark Worker）

发送端测试需要在spark-worker容器内执行，使用以下命令进入容器：

```bash
docker exec -it spark-worker bash
```

#### 3.2 准备接收端容器

接收端测试需要在另一个终端窗口中准备接收端环境。测试脚本会自动创建模拟接收器，但您需要确保网络连接正确配置，允许容器间通信。

## 测试流程

### 1. 测试文件位置

测试文件位于发送端容器内的以下位置：
- `/app/src/tests/test_sender_receiver.py` - 主测试文件
- `/app/src/tests/run_tests.py` - 测试运行脚本

**注意**：测试脚本中包含了模拟接收端的代码，您无需在接收端容器中运行额外的代码。测试会自动创建模拟接收器并在容器间建立通信。

### 2. 运行测试

在发送端容器（spark-worker）内，您可以通过以下两种方式运行测试：

#### 方式一：使用run_tests.py脚本

```bash
# 确保当前目录是 /app/src
cd /app/src

# 运行测试脚本
python tests/run_tests.py
```

#### 方式二：直接使用pytest

```bash
# 确保当前目录是 /app/src
cd /app/src

# 使用pytest运行测试
python -m pytest tests/test_sender_receiver.py -xvs
```

或者直接运行测试文件：

```bash
# 确保当前目录是 /app/src
cd /app/src

# 直接运行测试文件
python tests/test_sender_receiver.py
```

## 测试内容说明

测试会自动完成以下操作：

1. **模拟接收器启动**：测试会自动创建一个模拟的接收器服务，监听指定端口（默认为127.0.0.1:9000和9001）

2. **发送器初始化测试**：验证发送器能否正确初始化

3. **套接字设置测试**：验证网络套接字能否正确设置

4. **元数据连接测试**：验证发送器能否成功连接到接收器并发送元数据

5. **数据流传输测试**：验证发送器能否成功向接收器传输EEG数据流

## 常见问题排查

### 导入模块错误

如果测试失败并显示`ModuleNotFoundError: No module named 'eeg_reader'`等导入错误，请检查以下几点：

1. 确保您在正确的目录（`/app/src`）下运行测试
2. 检查Python路径是否正确设置
3. 可能需要修改导入语句，使用相对导入或完整的模块路径

### Java网关未启动

如果测试失败并显示无法连接到Java网关，请确保您已按照步骤2中的说明启动了Java网关服务。

### 端口占用问题

如果测试失败并显示端口被占用，可能是之前的测试没有正确释放端口。尝试以下解决方法：

1. 重启Docker容器
2. 修改测试中使用的端口（在测试文件中修改默认端口9000和9001）

### 网络连接问题

如果测试显示网络连接失败：

1. 确认Docker网络设置正确
2. 检查容器间的网络连接是否正常

## 自定义测试

如果您需要使用特定参数测试发送器，可以修改测试文件或直接使用发送器脚本：

```bash
# 在容器内运行发送器脚本，指定接收器地址和端口
python src/sender/sender.py --receiver-host 127.0.0.1 --receiver-metadata-port 9000 --receiver-data-port 9001 --subject-id 01 --task resting
```

## 注意事项

1. 测试使用模拟的EEG数据，不需要实际的EEG设备
2. 测试前必须手动启动Java网关服务
3. 测试会自动创建并启动模拟接收器，无需手动启动接收端
4. 所有测试都在容器内完成，不需要在宿主机上进行额外设置
